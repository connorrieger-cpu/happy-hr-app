# The original icon (before October 28, 2026)

The smiley-with-drinks logo the app launched with. To go back to it:

```bash
cp ios/design/icon-archive/2026-10-28-original/AppIcon-1024.png ios/HappyHR/Assets.xcassets/AppIcon.appiconset/
cp ios/design/icon-archive/2026-10-28-original/LogoMark.svg ios/HappyHR/Assets.xcassets/LogoMark.imageset/
```

`web/` holds the web app's icons from the same time (`web/public/icons/` and `web/public/favicon.svg`).
